character.gif がゲームで使用するキャラクター画像です（400x228・背景透過・加工なし）。

- 差し替える場合は、このフォルダに画像を置き、
  game.js の CONFIG.characterImage をそのパスに変更してください。
- 形式は PNG / GIF / SVG のいずれでも動作します。背景透過を推奨します。
- 表示サイズは高さ基準（CONFIG.characterWorldHeight）で正規化されるため、縦横比は自由です。
- 画像が読み込めない場合でも、代替のシルエット図形でゲームは正常に動作します。

キャラクター画像には平行移動・縦横比を保った拡大縮小・フェードのみを適用しています。
回転・反転・色変更・部分切り出し・重ね描画は行いません（詳細は ../README.md を参照）。
