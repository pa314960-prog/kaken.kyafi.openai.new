# キャッフィーの琵琶湖サバイバル

カメラの前で体を左右に動かして遊ぶ、ブラウザだけで完結するエンドレスランナーゲームです。
滋賀県のマスコットキャラクター「キャッフィー」を模したキャラクターを操作し、画面奥から迫ってくる網・釣り針・釣り糸を避け続けます。

## 起動方法

ビルドは不要です。ブラウザから直接 `index.html` を開くのではなく、**ローカルサーバー経由**で開いてください（カメラ利用やMediaPipeのモデル読み込みには `http(s)://` での配信が必要です）。

```bash
# このフォルダで実行
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## カメラ許可の手順

1. ページを開くと、ブラウザがカメラへのアクセス許可を求めるダイアログを表示します。
2. 「許可」をクリックしてください。
3. 許可すると自動的にモデルの読み込みが始まり、準備ができ次第「アイドル画面」が表示されます。
4. カメラの前に人が映ると自動的に「タイトル画面」に進みます。

### うまく動かないとき

- 誤って「ブロック」を選んだ場合は、ブラウザのアドレスバー付近のカメラアイコン（鍵アイコン）から許可をやり直し、ページを再読み込みしてください。
- 他のアプリ（Zoom、Teamsなど）がカメラを使用中だと起動できないことがあります。該当アプリを閉じてから再読み込みしてください。
- 通信環境が悪いとモデル（MediaPipe Tasks Vision の PoseLandmarker）の読み込みに失敗することがあります。その場合は日本語のエラー画面が表示されるので、内容を確認のうえ再試行してください。

## 画面の流れ

1. **アイドル画面** — 誰もいないときのデモ表示。人物を検出すると自動でタイトルへ。
2. **タイトル画面** — 「両手を挙げるとスタート」。両手を肩より上げるとキャリブレーションへ進みます。
3. **キャリブレーション** — 画面中央に立って3秒待つと、基準位置と肩幅を記録します。
4. **カウントダウン** — 3, 2, 1 の後にゲーム開始。
5. **プレイ** — 体を左右に動かしてレーンを移動し、障害物を回避します。ライフは3、制限時間は90秒。
6. **リザルト** — スコアとローカルランキング（TOP5）を表示。両手を挙げると再びキャリブレーションから再挑戦できます。
7. リザルト画面で30秒間誰も検出されなければ、自動的にアイドル画面へ戻ります。

すべてカメラのジェスチャーだけで一周でき、キーボードやマウス操作は不要です（エラー時の「もう一度試す」ボタンのみクリックが必要です）。

## キャラクター画像の差し替え方

`assets/character.png` を用意して配置するだけです。

- 縦長で、背景透過のPNGを推奨します。
- ファイルが存在しない場合は、自動的に代替のシルエット図形（ひげのある涙滴型のナマズ風シルエット）で動作します。エラーにはなりません。
- 別のファイル名にしたい場合は、`index.html` 内の `CONFIG.CHARACTER_IMAGE_PATH` を変更してください。

### キャラクター画像の取り扱いについて（重要）

キャッフィーは滋賀県の公式マスコットであり、使用に関する規程があります。本実装ではもっとも安全側のルールとして、キャラクター画像に対して以下の操作のみを行っています。

- 平行移動（`translate`）
- 縦横比を保った拡大縮小（`scale(s, s)` で縦横同一の値のみ使用）
- 表示・非表示（フェードを含む）

以下はコード内でキャラクター描画に一切使用していません。

- 回転（`rotate`）、傾き（`skew`）、左右反転（`scaleX(-1)` 等の非対称スケール）
- 縦横比を変える拡大縮小
- 色の変更（`filter` の `hue-rotate` / `saturate` / `invert` 等）
- 画像の一部だけを切り出す描画
- パーツ分割して個別に動かす処理（ひげだけを揺らす等）
- キャラクター画像の上に他の図形・文字・エフェクトを重ねる処理

カメラ映像は鏡のように左右反転して表示しますが（`ctx.scale(-1, 1)`）、この変換はカメラ映像の描画専用に限定し、`ctx.setTransform(1, 0, 0, 1, 0, 0)` で必ずリセットしてからキャラクターを描画しているため、キャラクター画像には反転が一切かかりません。

被弾時の演出（画面端が赤く光る）は画面全体のビネット効果として実装しており、キャラクター画像そのものには重ねていません。

## 調整パラメータ（`index.html` 冒頭の `CONFIG` オブジェクト）

すべての調整値は `index.html` の `<script type="module">` 内、先頭の `CONFIG` オブジェクトに集約しています。主なパラメータは以下の通りです。

| パラメータ | 説明 |
|---|---|
| `LANE_COUNT` | レーン数（3〜5推奨） |
| `LANE_LERP` | レーン間移動の滑らかさ（大きいほど速く追従） |
| `SMOOTHING_ALPHA` | 体の動きを平滑化する指数移動平均の係数 |
| `SHOULDER_WIDTH_LANES` | 肩幅の何倍ズレたら画面端に到達するか（移動の感度） |
| `CALIBRATION_SECONDS` | キャリブレーションにかける秒数 |
| `COUNTDOWN_SECONDS` | 開始前カウントダウンの秒数 |
| `RAISE_HANDS_HOLD_SECONDS` | 「両手を挙げた」と判定するまでの保持時間 |
| `MAX_LIVES` | ライフの数 |
| `TIME_LIMIT_SECONDS` | 制限時間（秒） |
| `INVINCIBLE_SECONDS` | 被弾後の無敵時間（秒） |
| `OBSTACLE_SPAWN_INTERVAL_START` / `OBSTACLE_SPAWN_INTERVAL_MIN` | 障害物の出現間隔（開始時／最短） |
| `DIFFICULTY_RAMP_SECONDS` | 出現間隔が最短になるまでの時間 |
| `OBSTACLE_FALL_SECONDS` | 障害物が奥から手前に到達するまでの時間 |
| `SCORE_PER_SECOND` | 1秒ごとの加点量 |
| `CHARACTER_IMAGE_PATH` | キャラクター画像のパス |
| `CHARACTER_BASE_SIZE` | キャラクターの基準表示サイズ |
| `CHARACTER_ISOLATION_RATIO` | キャラクター周囲に確保する余白比率 |
| `RESULT_IDLE_TIMEOUT_SECONDS` | リザルト画面からアイドル画面へ自動復帰するまでの秒数 |

これらの数値を書き換えるだけで、レーン数・移動感度・難易度カーブ・ライフ数・制限時間などを調整できます。

## 技術構成

- 姿勢推定: [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) の `PoseLandmarker`（CDN経由で読み込み）
- 描画: Canvas 2D
- ループ: `requestAnimationFrame`
- フレームワーク不使用、素のJavaScript（ESモジュール）
- ランキング保存: `localStorage`
